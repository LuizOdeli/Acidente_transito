# Auditoria

## Objetivo

Verificar se a análise produzida está de acordo com os fatos, evidências e fontes jurídicas disponíveis no caso.

## Prompt

Realize uma auditoria da análise apresentada.

Verifique:

1. se os nomes e veículos correspondem aos documentos do caso;
2. se a data, horário e local estão corretos;
3. se os relatos dos dois condutores foram representados corretamente;
4. se fatos comprovados foram diferenciados de alegações;
5. se houve criação de informações não presentes nos documentos;
6. se os danos dos veículos foram descritos corretamente;
7. se os dispositivos legais utilizados correspondem às fontes disponíveis;
8. se alguma conclusão foi apresentada com grau de certeza superior ao permitido pelas evidências;
9. se existem contradições entre os documentos;
10. se existem pontos relevantes que ainda dependem de comprovação.

Apresente as inconsistências encontradas e indique a correção necessária.

Não crie novos fatos durante a auditoria.
